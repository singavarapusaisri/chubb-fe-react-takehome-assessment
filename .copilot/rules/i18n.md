# Localization & Formatting Framework

## 1. Structural Localization Rule
* While the interface language remains English (APAC Operations), you must avoid embedding hardcoded currency symbols or loose localized date strings directly into components.

## 2. Functional Normalization
* Currency Conversions: Format premium figures using the standard browser localization framework:
  `new Intl.NumberFormat(undefined, { style: 'currency', currency: policy.currency }).format(amount)`
* Calendaring Standard: Format dates strictly using standard international representation (`YYYY-MM-DD`) or regional structures (`DD MMM YYYY`), running all data processing steps safely through an isolated formatting utility file.
